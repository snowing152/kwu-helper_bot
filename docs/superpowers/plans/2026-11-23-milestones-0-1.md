# Milestones 0-1 (Survey + Crawler) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the student survey, and build a polite crawler that downloads the milestone-1 sources, extracts clean text, and records each document in a manifest with change detection.

**Architecture:** A small `kwu_helper.crawler` package. A fixed source registry feeds an async fetcher (httpx, rate-limited, with retries). HTML is decoded and reduced to plain text (tables kept as rows). A file-based store writes text files plus a JSON Lines manifest and reports `new` / `changed` / `unchanged` per document by hashing the extracted text. A CLI ties it together and prints a summary. Postgres is not used until milestone 2.

**Tech Stack:** Python 3.13+, uv, httpx, beautifulsoup4, pytest, pytest-asyncio, ruff, mypy (strict).

**Spec:** `docs/superpowers/specs/2026-11-23-kwu-helper-design.md`

## Global Constraints

- `requires-python = ">=3.13"`. Layout: `src/kwu_helper/`, tests in `tests/`.
- Runtime dependencies: only `httpx` and `beautifulsoup4`. Dev dependencies: only `pytest`, `pytest-asyncio`, `ruff`, `mypy`. Anything else needs the user's approval first.
- `data/` and `.env` are in `.gitignore`. No scraped content is ever committed. Test fixtures are small synthetic HTML written by hand.
- User-Agent: `kwu-helper-crawler/0.1 (student project)`. No personal data in any request.
- At most 1 request per second to any host. Timeout 20 s. At most 3 attempts per URL. Retry only on timeouts, connection errors and 5xx responses.
- One failed source never stops the crawl. Failures are reported in the summary.
- No emojis anywhere. Comments explain why, not what. Public functions and classes have docstrings.
- Errors are handled explicitly. No bare `except:` and no silently swallowed exceptions.
- Commits use Conventional Commits and are made only when the user has approved them.
- Every task ends green on `uv run pytest`, `uv run ruff check .`, `uv run ruff format --check .` and `uv run mypy src tests`.

## Review Focus

1. A page served as EUC-KR, or with a missing or wrong charset header, must decode to readable Korean, not mojibake. Pinned in Task 3.
2. One source that times out, returns 404 or returns 500 must be reported as failed while the other sources are still saved. Pinned in Task 6.
3. Re-crawling a page whose HTML changed only in boilerplate (a visitor counter or timestamp outside the content area) must report `unchanged`, so the text is hashed, not the raw HTML. Pinned in Task 5.
4. A page whose content area extracts to almost no text (a JS-rendered page or a wrong selector) must be reported as failed, not saved as an empty document. Pinned in Task 3.
5. The same notice appearing on two list pages (a new post shifts the pages) must be fetched and saved once. Pinned in Task 4.

- [ ] **Step 3: Implement `extract.py`**

- `decode_html` tries, in order: the charset from the header, then the charset from `<meta>`, then UTF-8, then EUC-KR (CP949 superset: use `"cp949"`). The first one that decodes without errors wins, and the stdlib does the decoding.
- `extract_page` uses BeautifulSoup with `"html.parser"`. It removes `script, style, nav, header, footer, noscript`, then narrows to the selector if one is given (or `body`). Each table row becomes one line of cells joined by `" | "`. Whitespace is collapsed per line and empty lines are dropped. The title comes from `<title>`, or else the first `h1`/`h2`, or else `""`. Attachment links are hrefs ending in `.pdf .hwp .hwpx .doc .docx .xls .xlsx`, case-insensitive, resolved with `urljoin`. Raise `EmptyContentError` if `len(text) < MIN_TEXT_CHARS`.
